Development Builds


Development builds are not recommended for any public server that is meant for people to join outside of testing purposes. If you downloaded an indev build from GitHub, go back to the GitHub releases and click on the latest release that doesn't have build in the name. Or, go to Modrinth or Hangar to get the production ready build.
If you actually do want to run the testing builds, the only real purpose I can think of someone using it for it testing for bugs so they can report them.
