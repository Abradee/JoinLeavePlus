## How to configure messages

You can easily configure the join and leave messages with this plugin, you can change a first time join message. And, it is very simple to do.

Location: 
```
/server/plugins/JoinLeavePlus/config.yml
```

Default config: 
```
first-time-join: "&6&l[+] &b&l%player% &ejoined for the first time!"
join: "&a&l[+] &a%player% &7has joined."
leave: "&c&l[-] &c%player% &7has left."
```
